# Milestone 12 — YouTube Publishing Security, Token Encryption & Compliance
## Creator Studio AI Security Specification

**Project Owner:** Muhammad Ali ([alibuild.site](https://alibuild.site))  
**Milestone:** M12 of 15  
**Topic:** Secret Hygiene, Cryptography, OAuth Security & YouTube Policy Compliance

---

## 1. OAuth 2.0 State & CSRF Protection

- **State Parameter Construction:**
  - State token format: `<user_id>:<channel_id>:<nonce>:<timestamp>:<signature>`.
  - Signature is computed using HMAC-SHA256 with the server's master secret key (`APP_MASTER_ENCRYPTION_KEY`).
  - Maximum token lifetime: 10 minutes (600 seconds).
  - Verification validates the HMAC signature, channel ownership, and timestamp freshness before exchanging authorization codes.

---

## 2. AES-256-GCM Token Encryption at Rest

- All Google OAuth `refresh_token` strings and resumable session URIs are classified as High Sensitivity (Tier 1).
- Stored exclusively as ciphertext in the database (`oauth_refresh_token_encrypted`, `session_uri_encrypted`).
- Encryption algorithm: **AES-256-GCM** (Galois/Counter Mode) via `app.utils.crypto`:
  - 96-bit random IV/nonce per encryption call.
  - 128-bit authentication tag guarantees ciphertext integrity against tampering.
  - Secret key derived from `settings.APP_MASTER_ENCRYPTION_KEY` using SHA-256 HKDF if necessary.

---

## 3. Secret Leakage Prevention & Sanitization

1. **API Responses:**
   - Pydantic schemas (`ChannelResponse`, `PublishingJobResponse`, `YouTubeUploadSessionResponse`) strictly omit all tokens, session URIs, and authentication secrets.
   - Status endpoints return only:
     - Sanitized channel metadata (title, custom URL, subscriber count, connection status).
     - Byte-level metrics (`bytes_uploaded`, `total_bytes`, `progress_percent`).
     - Error messages without API keys or authorization headers.

2. **Application Logging:**
   - Loguru formatters and uploader modules filter out `Authorization` headers, `Bearer` tokens, and query parameters containing secrets before logging.
   - Resumable session URIs (which act as bearer capabilities) are obfuscated in logs: `https://www.googleapis.com/upload/.../sessions/[REDACTED]`.

---

## 4. Multi-Tenant Isolation & Least Privilege

- **Channel Isolation:**
  - Standard creators can only publish to channels owned by their `user_id`.
  - Projects can only be published to the channel assigned to the project.
  - Super Admins can publish across channels, with comprehensive audit trails.
- **YouTube OAuth Scopes:**
  - Only two scopes are requested:
    - `https://www.googleapis.com/auth/youtube.upload`
    - `https://www.googleapis.com/auth/youtube.readonly`
  - No general Google account access, Drive access, or Gmail permissions are ever requested.

---

## 5. YouTube Policy & Synthetic Media Declaration Compliance

Under YouTube's Altered and Synthetic Content Disclosure Policy:
- All videos generated by Creator Studio AI utilize AI voice narration and synthesized or AI-assisted visuals.
- The publishing service explicitly sets:
  - `status.selfDeclaredMadeForKids = false` (educational/tech content intended for general audience).
  - `status.containsSyntheticMedia = true` (transparently flagging AI generation in YouTube Studio).
- Default privacy is enforced as `unlisted` or `private` unless explicitly configured by the creator, preventing accidental public disclosure before manual review if desired.
